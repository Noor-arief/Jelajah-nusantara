## NUSA
NUSA is JelNusa's AI travel assistant. It can help with destination ideas, itinerary structure, budget guidance, packing considerations, and general travel questions.

NUSA does not make bookings or process payments. Travel details that can change should be verified with current official or authoritative sources.

## Repository
This repository contains the public JelNusa website and its supporting frontend, GEO/SEO discovery assets, multilingual content, and affiliate-routing integration.
